# 产品心智模型 · 心绪日记 / HeatMoment

> **本文是什么**：这是「心绪日记」/ HeatMoment 这款产品的**公理层**——回答「产品是什么、由哪些对象构成、它们的语义与规则」，而不是「怎么实现」。任何实现、能力边界或计划都必须能追溯到这里，若某个实现或计划与本文的公理冲突，是实现/计划错了，而不是反过来改本文。
>
> **本文不是什么**：不含任何实现细节（无技术栈、无控件、无字段、无页面命名）。已实现事实进入 `docs/current/`；未完成计划进入 `docs/plans/`。
>
> **来源**：本模型由团队重新提炼，真机行为、既有产品观测记录仅作输入。情绪名称以真机为准。

---

## 第一层 · 本质：产品到底是什么

**一句话**：时刻是一条条带**情绪身份**的**生活记忆**，挂在一条**可回看、可筛选、可整理**的**个人时间轴**上。

它是私人的、本地优先的记录工具，重心是让"记录 — 回看"这件事保持低负担、可浏览、可定位、可整理。核心主线：

```
记录一个时刻
  → 在时间轴上阅读它
  → 用心情和标签理解它
  → 用热力图回到某段时间
  → 在主场景之上用临时任务处理预览/编辑/管理
  → 用删除与恢复管理它是否还属于我的时间轴
```

**它不追求成为**：社交发布、多端协同、复杂 AI 分析、皮肤市场、独立的一级"回看/分析"页面、深度时间范围筛选。（iCloud 同步、隐私锁、语言、订阅是**支撑能力**，不是核心心智对象——它们服务于记录的安全与边界，产品结构不围绕它们展开，已实现事实归 current，未完成工作归 plans。）

## 第二层 · 对象：产品由哪些东西构成

产品不是一堆页面，是一组**对象**。每个对象有稳定的：**本质 / 组成符号 / 状态 / 跨位置一致语义 / 与其他对象的关系**。按职责分五类。

### A. 内容对象

#### 时刻（记忆本体）
- **本质**：一条生活记忆，不是一张普通文本卡片。
- **组成符号**：发生时间、心情、标签、标题、正文、照片。
- **要点**：「发生时间」是"这件事发生在什么时候"，可指向过去（补记），与"记录进来的时刻"是两回事。
- **状态**：正常 / 在垃圾箱 / 已彻底删除（状态变化交由「删除生命周期」）。
- **跨位置一致**：在时间轴上被拆成"时间戳 + 心情节点 + 气泡"三个阅读部件；被阅读时以一张浮起的阅读卡片完整呈现。
- **关系**：承载唯一一个心情；可挂多个标签；被时间轴组织；受删除生命周期管理。

### B. 语义对象

#### 心情（情绪身份）—— 产品的核心语义
- **本质**：时刻的**情绪身份**。它不是一个装饰性色点，也不只是一个 emoji，而是一套**贯穿全局的语义**。
- **八个情绪身份**（并列，非 1–5 评分量表）：正常、开心、难过、焦虑、恐惧、愤怒、厌恶、激励。
- **组成符号**：名称、emoji、图标、**心情色**、节点形态。
  - emoji：轻量识别与"当前筛选条件"的提示。
  - 图标：筛选菜单、编辑入口里的明确识别。
  - 心情色：见下方公理。
- **心情色是跨位置的一致语义**（本模型的关键定调）：**每种情绪拥有唯一的心情色**，这个颜色在时间轴节点、热力图、统计三处表达**同一个情绪身份**，不是任何一处的局部装饰，也不存在"统一色点"。一次记录选择某个情绪，这条身份就沿以下链条一致地显形：

```
一次记录选「开心」
  → 时间轴出现「开心」节点（用开心的心情色）
  → 筛选里可以选「开心」（图标 + 名称）
  → 当前筛选条件标记显示「开心」（emoji + 名称）
  → 热力图对应日期呈现「开心」的心情色
  → 统计里「开心」参与年度分布（用开心的心情色）
```

- **状态**：在选择器中被选中/未选中；作为筛选条件时激活/未激活。
- **关系**：定义时刻的情绪身份；驱动时间轴节点着色、热力图着色、统计着色，并构成筛选的一个维度。

#### 标签（主题线索）
- **本质**：时刻的主题归类线索。它与内容是"归类"关系，**不是"所有权"**。
- **组成符号**：名称（以 `#标签名` 呈现）。
- **能力**：编辑时刻时选择已有标签、在管理区集中创建/重命名/删除、作为筛选条件。
- **要点**：删除一个标签只移除这条分类线索——用过它的时刻会失去该标签，但标题/正文/照片/时间/心情全部保留。**删标签 ≠ 删时刻**。
- **入口归属**：标签创建是管理任务，归属管理区；编辑时的标签选择和首页筛选只消费已有标签，不临时创建标签。
- **关系**：多对多地挂到时刻；与心情并列为两大筛选维度；改变时间轴的可见内容。

### C. 回看与定位对象

#### 时间轴（主舞台）
- **本质**：所有时刻的主场景，用户**始终站在这里**。
- **组织**：按发生时间倒序。
- **阅读单元**：时间戳（何时）+ 心情节点（当时什么情绪，用该情绪的心情色）+ 气泡（标题、正文摘要、标签、照片）。
- **状态**：完整浏览 / 筛选态（内容集合被缩小）/ 定位态（滚动到某时间段并高亮）。
- **首页标题的双重身份**：主场景标题「时刻」随时间轴滚动切换角色——**展开态**（滚到顶）是纯粹的**场景标识**，只强调「这里是主时间轴」，不可点、不承担筛选；时间轴上滑、标题折叠进顶部栏成为**收起态**后，它才转为**筛选入口**（打开标签/心情筛选）。即「筛选入口」是标题在收起态下才承担的角色，展开态不承担。这与公理 5 一致——用户始终在主场景，标题只是随滚动切换呈现与角色。
- **关系**：展示时刻；被上下文标记描述当前条件；被热力图定位；新建、预览、删除的入口都从这里发起。

#### 上下文标记（当前条件的可见表达）
- **本质**：告诉用户"现在看的是完整记录，还是某个筛选/某个时间位置"。它不是内容，是**当前查看条件的可见说明**。
- **两类标记**：
  - 筛选标记：`#标签`、情绪（emoji + 名称）——说明"当前只看满足条件的时刻"。
  - 时间标记：年 / 月 / 日——说明"当前定位到某个时间点"。
- **要点**：两类可**同时存在但含义不同**。移除筛选标记改变的是"看哪些记录"；移除时间标记改变的是"是否停在某个时间位置"。
- **关系**：反映筛选（标签/心情）与热力图定位的当前状态。

#### 热力图（回看与定位）
- **本质**：时间轴上的**回看 + 定位**工具，不是独立页面、不是普通日历。
- **压缩层级**：年 → 月 → 日期格（是否有记录 / 当天情绪印象 / 记录数量）。
- **颜色来自心情色**：某天有记录时，日期格用**当天最后一条时刻的心情色**表达当日情绪印象；没有记录则为空态。于是"一年的情绪分布"成为一幅**彩色图案**，不必打开每条记录就能看见。
- **两种行为**：切换年份（换整年回看范围、清除时间锚点）；选择月/日（高亮并把时间轴滚动定位到相关记录，再点同一处取消）。
- **与筛选正交**：热力图选择只负责"去哪个时间位置看"，**不改变"看哪些记录"**；但热力图会跟随当前筛选口径，展示"当前条件下的年度分布"。
- **关系**：消费心情色；与筛选是两个正交维度（见公理 2）；通过时间标记表达当前锚点。

### D. 层级对象（两种本质不同的浮层关系）

#### 任务卡片栈（临时任务层级）
- **本质**：在主场景**之上**处理临时任务的层级关系——用户没有离开时间轴，只是在它上面叠了一张临时卡片。
- **层级效果**：当前卡片浮在最前；上一层卡片**下沉、缩小、露在后面**；更早的层级暂不显示；关闭最前一层，上一层重新浮回；关闭最后一张才回到时间轴。（这就是"卡片层叠"的语义。）
- **承接的任务**（只按任务重量区分，不描述具体页面）：阅读、编辑、管理、权益说明。
- **预览是弹出的阅读卡片**（本模型定调）：点一条时刻，是在当前时间轴上**弹出一张阅读卡片**，不是跳转到另一个页面。
- **关系**：承载时刻的预览与编辑、长期管理、权益说明；语义是"临时、可层叠、完成即回主场景"。

#### 就地选择层（局部选择工具）
- **本质**：在当前上下文里调整条件或字段值的临时层。它不代表一个完整任务，不 push 新页面，不进入任务卡片栈；用户仍然站在时间轴或编辑卡片里。
- **与任务卡片的根本区别**（本模型定调）：
  - 任务卡片 → 背景**下沉、上一层缩小**，进入层级栈。
  - 就地选择层 → 背景**不进入任务卡片层叠语义**，不 push、不入全局路由栈，只在当前上下文之上临时调整条件或值。
- **两种呈现形态**：
  - **首页筛选 sheet**：从时间轴收起态标题/筛选入口打开的半屏 sheet，语义是"留在主页，精炼当前时间轴内容"。它不因点选条件自动关闭，用户可连续调整后通过系统下滑手势手动关闭。
  - **就近浮窗**：从编辑卡片的字段锚点旁就近弹出，依附锚点、带指向锚点的尖角、尺寸随内容自适应；用于日期、时间、编辑时的心情/标签等单条时刻字段选择。
- **筛选能力**：心情筛选为单选，可切回全部心情；标签筛选为多选，可清空标签条件；多个标签被选中时，时间轴只显示**同时包含这些标签**的时刻（AND 语义）；清除全部一次性移除心情与标签筛选。每次点选后，时间轴、上下文标记和热力图口径即时响应；选择条件不代表任务完成，sheet 不自动消失。
- **交互边界**：筛选改变"看哪些记录"；热力图只负责"定位到哪个时间位置"。两者可以同时存在，但不能混成同一个状态。

### E. 生命周期对象

#### 删除生命周期
- **本质**：时刻的一段**状态变化**，不是一个孤立按钮。它回答的是"用户只是暂时不想看到，还是已经决定彻底放弃"。
- **三态与语义**：
  - 正常时刻：出现在浏览、筛选、热力图、统计口径中——"这是正在使用的生活记录"。
  - 垃圾箱时刻：从主时间轴消失、只在垃圾箱可管理，但可恢复——"暂时移除，仍可找回"。
  - 彻底删除：不再作为一个时刻存在——"用户放弃恢复机会"。
- **动作语义**：主时间轴删除 = "先移出主时间轴"（有垃圾箱兜底，故不必二次确认）；恢复 = "这条记录重新属于我的时间轴"（带着原时间/心情/标签/内容回归）；彻底删除 = 不可逆的终态（需二次确认）。
- **关系**：决定一条时刻是否参与时间轴、筛选、热力图与统计。

## 第三层 · 公理：不可违背的规则

任何设计决策与以下规则冲突，即为设计错误：

1. **心情色一致性**：心情色是跨时间轴节点、热力图、统计的**同一情绪语义色**；不得降为局部装饰，不得用统一色点替代按情绪着色。
2. **定位 ≠ 筛选**：热力图定位改变"去哪个时间位置看"（滚动位置），筛选改变"看哪些记录"（内容集合）；两个正交维度，可叠加、不可合并。
3. **删除是生命周期**：删除意味着进入"可恢复的垃圾箱态"，只有彻底删除才是终态；不是即时消失。
4. **两种浮层层级**：任务卡片下沉入栈（层叠），就地选择层不进入任务卡片栈；短路径条件/字段调整用就地选择层，完整任务用任务卡片，二者不可混用。就地选择层可按内容重量呈现为首页筛选半屏 sheet 或字段就近浮窗。
5. **永不离开主场景**：一切临时任务都在时间轴**之上**展开，完成即回到时间轴；不存在与时间轴并列的第二个一级场景。
6. **对象归属原则**：新增任何交互，先判定它属于哪个对象；同一对象在任何位置保持同一套语义，不做散装入口。
7. **标签是归类不是所有权**：删除标签只移除分类线索，绝不删除时刻内容。
8. **以发生时间组织**：时刻的排序、回看、统计都以"发生时间"为准，以支持补记。

## 第四层 · 组合：对象如何串成一套体验

```
时刻     —— 带着发生时间、心情、标签、标题、正文、照片进入时间轴
时间轴   —— 用时间戳、心情节点、气泡展示每一条时刻
心情     —— 用名称/emoji/图标/心情色，贯穿节点、筛选、热力图、统计
标签     —— 用 #标签名 组织主题，并改变时间轴可见内容
上下文标记 —— 用标签、心情、年/月/日说明当前时间轴的查看条件
热力图   —— 用日期格的心情色展示年度情绪分布，并把时间轴带回某个时间点
任务卡片栈 —— 用可层叠的卡片承接阅读、编辑、管理、权益任务
就地选择层 —— 用首页筛选半屏 sheet 或字段就近浮窗承接筛选、日期、时间等就地选择
删除生命周期 —— 用垃圾箱与恢复管理一条时刻是否仍属于主时间轴
```

**新交互归属判据**（防止做成散装入口）：

| 新交互想表达什么 | 归属对象 |
| --- | --- |
| 一条记录的内容、时间、照片 | 时刻 |
| 情绪状态、颜色、图标、统计 | 心情 |
| 主题分类、整理、筛选 | 标签 |
| 当前看的是哪些记录、定位在哪段时间 | 上下文标记 |
| 年度分布、日期回看、时间定位 | 热力图 |
| 临时阅读、编辑、管理、权益说明 | 任务卡片栈 |
| 就地筛选多个条件 | 就地选择层 |
| 就地选择一个字段值 | 就近浮窗 |
| 暂时移出、恢复、彻底移除一条记录 | 删除生命周期 |

新能力若无法归入现有对象，须先判断它是"现有对象的扩展"还是"应成为一个新的产品对象"，再进入设计。
