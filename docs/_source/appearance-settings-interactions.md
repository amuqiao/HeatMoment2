# Appearance Settings Interactions

> 本文说明外观主题页当前各项设置的交互逻辑、用户可见影响和边界；“主色”影响是其中一部分，不代表整页全部交互。

## 文档边界

本文只记录当前已经落地的外观主题页事实，主要面向需要理解产品视觉行为、设置交互、设计验收和文档维护的人。

本文不作为新增主题、扩展色板、开放皮肤列表或重构视觉系统的计划文档。相关扩展应单独定义目标、开放范围、持久化边界和验收条件，不在本文内展开。

## 核心模型

外观主题页当前把用户可操作项拆成两类：外观轴和内容行为偏好。

```text
外观轴
  ├── 显示模式：决定明暗和中性色基底
  ├── 主色：决定强调色和强调色的柔和状态
  └── 背景纹理：决定背景图案是否出现以及图案形态

内容行为偏好
  └── 照片显示：决定照片在时间轴中的呈现方式
```

其中，“主色”不是全局换肤，也不是替换所有颜色。它只改变当前外观中的强调色系统：强调操作、选中状态、部分提示和由强调色派生的背景纹理颜色。

## 用户可见入口

用户从首页进入设置流，再进入“外观主题”。当前页面包含：

| 设置项 | 当前作用 |
| --- | --- |
| 显示模式 | 在浅色和深色外观之间切换 |
| 主色 | 在紫色、红色、橙色、绿色、青色、紫罗兰之间切换强调色 |
| 背景纹理 | 在无纹理、网格、点阵之间切换背景图案 |
| 照片显示 | 在滚动和轮播之间切换照片展示方式 |

页面底部当前文案为“只改变外观，不影响已记录的内容、标签和统计数据。”这句话描述的是用户侧结果：调整这些设置不会改写内容数据。

设置列表入口副标题当前会概括提到“气泡”，但进入外观主题页后，当前可操作项仍只有显示模式、主色、背景纹理和照片显示。当前外观页没有开放皮肤列表、整体配色方案、气泡样式、心情节点样式、时间轴轨道样式、业务图标包、背景插画或表面材质选择。即使内部已经存在部分开发者变体轴，它们也不是当前用户可以通过设置页修改的能力。

## 显示模式交互

显示模式用于切换浅色和深色体验。它影响的是基础视觉层级，而不是单个强调色。

用户切换显示模式后，会看到这些变化：

- App 背景、面板、卡片、设置 sheet 和预览画布切换到对应明暗基底。
- 文本层级、边框、弱化说明和热力图空值底色切换到对应明暗版本。
- 当前主色槽位保持不变；例如用户选择“绿色”主色后，再切换明暗模式，强调色仍然是绿色，只是周围基底变成浅色或深色。
- 背景纹理的形态保持不变，但纹理在不同明暗模式下会使用适合当前基底的透明度。

显示模式不改变记录内容、照片、标签、统计数据，也不改变照片显示方式。

## 主色会影响什么

主色修改后，用户会看到 App 中“强调关系”发生变化。当前影响可以按产品语义理解为：

| 影响区域 | 用户看到的变化 |
| --- | --- |
| 主要行动入口 | 新建、保存、确认、返回、关闭等强调操作使用新的主色或主色前景组合 |
| 当前选择状态 | 筛选、外观选项、年份选择、日期 / 时间选择器等选中或聚焦状态使用新的主色或柔和主色 |
| 设置流视觉重点 | 设置页图标底色、入口图标、选项边框、诊断提示边框等跟随主色 |
| 编辑体验 | 日期 / 时间 pill、标签选择、照片添加动作、可保存状态等强调元素跟随主色 |
| 预览与标签表达 | 预览页编辑入口、标签胶囊、部分标签文字或背景跟随主色 |
| 回看体验 | 热力图中的今日边框、年份选择和月份聚焦态等跟随主色 |
| 背景纹理颜色 | 当背景纹理开启时，纹理线条或点阵使用由主色派生的低透明度颜色 |

这些影响不是因为每个页面单独保存一份颜色，而是因为页面共同消费同一套强调色语义。用户换主色后，已经打开或随后进入的界面会按新的强调色呈现。

## 主色不会影响什么

主色不代表所有颜色都被替换。当前明确不受主色直接控制的部分包括：

| 不受主色控制的对象 | 边界说明 |
| --- | --- |
| 记录内容 | Moment 的标题、正文、时间、照片、标签归属和统计结果不会被改写 |
| 心情色 | 平静、开心、低落、焦虑、害怕、生气、厌烦、有动力等心情颜色保持独立语义 |
| 危险色 | 删除、失败、购买页部分高风险或强调商业动作使用独立危险色，不跟随主色 |
| 中性色基底 | 背景、面板、文字、边框等基础层级主要由显示模式和当前配色方案决定 |
| 开发者变体轴 | 气泡样式、心情节点样式、时间轴轨道样式、业务图标包不因用户改主色而切换 |
| 照片展示行为 | 滚动或轮播由“照片显示”控制，不由主色控制 |
| 未开放外观轴 | 皮肤、气泡、心情节点、时间轴轨道、业务图标包、背景插画和表面材质不会因用户改主色而切换 |

因此，验收主色修改时不应期待心情节点变成主色，也不应期待删除按钮、错误提示、Pro 页危险按钮或热力图日期选中边框都跟随主色。日期选中边框当前使用主文本色，不属于主色影响面。

## 背景纹理交互

背景纹理控制背景图案形态，而不是控制背景基底颜色。

当前可选结果是：

| 选项 | 用户看到的变化 |
| --- | --- |
| 无纹理 | 背景只保留当前明暗模式下的渐变基底 |
| 网格 | 背景叠加低透明度网格线 |
| 点阵 | 背景叠加低透明度点阵 |

纹理颜色来自当前主色，所以用户改主色后，已开启的网格或点阵会随之换色。用户关闭纹理后，主色仍会影响其他强调元素，但背景上不再出现纹理。

背景纹理不开放背景插画，也不改变气泡、心情节点或时间轴轨道样式。

## 照片显示交互

照片显示是内容行为偏好，不是外观主题轴。

当前可选结果是：

| 选项 | 用户看到的变化 |
| --- | --- |
| 滚动 | 时间轴照片以横向缩略图条呈现 |
| 轮播 | 时间轴照片以轮播方式呈现 |

照片显示只影响照片在时间轴中的浏览方式，不改变照片文件、记录内容、主色、显示模式、背景纹理或统计数据。应用皮肤或调整主色也不应顺带改变照片显示方式。

## 设置项关系

主色、显示模式、背景纹理和照片显示是不同维度。

| 维度 | 改变什么 | 不改变什么 |
| --- | --- | --- |
| 显示模式 | 明暗、背景基底、面板和文本层级 | 不改变用户选择的主色槽位 |
| 主色 | 强调色、柔和强调色、强调状态和纹理颜色 | 不改变明暗基底、心情色、危险色和照片展示方式 |
| 背景纹理 | 背景是否出现网格或点阵 | 不改变主色槽位；纹理颜色仍从当前主色派生 |
| 照片显示 | 时间轴照片滚动或轮播 | 不属于外观主题轴，不改变颜色 |

一个典型判断是：如果变化表达“当前选中、可以行动、正在聚焦”，通常应跟随主色；如果变化表达“内容本身、心情语义、危险动作、阅读层级”，通常不应跟随主色。

## 偏好与异常呈现

外观修改采用“先更新当前界面，再保存偏好”的体验。

- 用户点选主色后，当前界面立即使用新的强调色。
- 如果保存失败，当前界面不会回滚，外观页会显示“外观设置保存失败，请稍后重试”。
- 如果本地外观或照片显示偏好存在坏配置，App 会使用可用默认值或迁移值继续运行，并在外观页显示“已修正 N 项本地偏好配置”。
- 照片显示保存失败时，外观页显示“照片显示设置保存失败，请稍后重试”，它和主色保存失败分开反馈。

这意味着视觉状态和持久化状态不是同一件事：用户当前看到的颜色可以已经更新，但下次启动是否保留取决于偏好保存是否成功。

## 验收检查

检查设置页主色修改时，优先覆盖这些用户可见点：

1. 外观页色点选中态会变化。
2. 设置流的返回、关闭、入口图标和统计预览强调色会变化。
3. 首页的新建入口、顶部操作、筛选选中态和时间轴标签强调色会变化。
4. 编辑器保存状态、日期 / 时间选择状态、标签选择和照片添加入口会变化。
5. 预览页编辑入口和标签视觉会变化。
6. 热力图当前焦点、今日边框或年份选择强调态会变化。
7. 开启背景纹理后，纹理颜色会跟随主色变为低透明度的主色。
8. 心情色、删除 / 错误危险色、正文内容、照片展示方式、标签归属和统计数据不会因为主色改变而变化。
9. 切换显示模式时，主色槽位保持不变，但背景、面板、文本和边框层级切换到对应明暗版本。
10. 切换照片显示时，只改变时间轴照片浏览方式，不改变颜色。

如果某个新增 UI 需要表达选中、聚焦或主要行动，应优先接入现有强调色语义；如果它表达心情、危险、内容层级或结构背景，应先确认是否应该使用其他语义色。
