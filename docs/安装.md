# 真机安装到自己的 iPhone

本文说明如何把当前本地开发版「心绪日记」/ HeatMoment 安装到自己的 iPhone 上，不经过 App Store，也不走 TestFlight。

## 先理解这件事

真机安装和模拟器运行不是一回事：

- 模拟器可以用 `CODE_SIGNING_ALLOWED=NO` 构建运行。
- iPhone 真机必须由 Xcode 使用你的 Apple ID / Team 签名。
- 当前项目默认不接入 iCloud / CloudKit entitlement，便于 Personal Team 直接真机调试。
- `Config/HeatMoment.entitlements` 仍保留，未来需要 iCloud 同步时再用支持 iCloud 的付费 Team 启用。

最终安装到手机上的不是源码，而是 Xcode 构建并签名后的 `HeatMoment.app`。

## 1. 生成 Xcode 工程

在仓库根目录执行：

```bash
./scripts/gen.sh
```

看到类似输出即可：

```text
Created project at .../HeatMoment.xcodeproj
[HeatMoment] 已生成 HeatMoment.xcodeproj
```

如果 Xcode 已经打开旧工程窗口，建议先关闭 Xcode 里的项目窗口，再重新打开生成后的 `HeatMoment.xcodeproj`，避免 Xcode 继续使用旧的签名配置。

## 2. 打开工程

双击打开：

```text
HeatMoment.xcodeproj
```

不要手改 `.xcodeproj` 文件；工程配置来源是 `Project.yml`，需要变更工程结构时重新执行 `./scripts/gen.sh`。

## 3. 连接 iPhone

1. 用数据线连接 iPhone 和 Mac。
2. iPhone 上出现“信任此电脑”时点信任。
3. 输入 iPhone 锁屏密码确认信任。
4. Xcode 顶部设备下拉框选择你的 iPhone，而不是模拟器。

## 4. 配置 Signing

在 Xcode 里：

1. 左侧点最上面的蓝色 `HeatMoment` 项目。
2. 中间 `TARGETS` 选择 `HeatMoment`。
3. 打开 `Signing & Capabilities`。
4. 勾选 `Automatically manage signing`。
5. `Team` 选择你的 Apple ID / Personal Team。

正常情况下，当前项目不应显示 `iCloud` capability。如果仍看到 iCloud，说明 Xcode 可能还在用旧工程，关闭项目窗口后重新打开 `HeatMoment.xcodeproj`。

## 5. Bundle Identifier 冲突时

如果 Xcode 报：

```text
The app identifier "com.heatmoment.app" cannot be registered
No profiles for 'com.heatmoment.app' were found
```

说明这个 Bundle Identifier 不属于你的 Team，或不能由你的 Personal Team 创建。把 `Signing & Capabilities` 里的 `Bundle Identifier` 改成你自己的唯一值，例如：

```text
com.yourname.heatmoment.dev
```

只要能保持唯一即可。真机本地安装不要求和最终上架 Bundle ID 一致。

## 6. 点击 Run

确认顶部目标设备是你的 iPhone 后，点击 Xcode 左上角 Run。

第一次签名时，macOS 可能弹出：

```text
codesign 想要访问你的钥匙串中的密钥 "Apple Development: ..."
```

这是正常现象。Xcode 正在用 Apple Development 证书私钥给 App 签名。

这里输入的是 **Mac 登录密码**，不是 Apple ID 密码，也不是 iPhone 密码。可以点：

- `允许`：本次允许，之后可能还会弹。
- `始终允许`：以后 Xcode 签名时少弹这个提示。

## 7. 开启 Developer Mode

如果 Xcode 报：

```text
Developer Mode disabled
To use ... for development, enable Developer Mode in Settings -> Privacy & Security.
```

在 iPhone 上操作：

1. 打开 `设置`。
2. 进入 `隐私与安全性`。
3. 找到 `开发者模式`。
4. 打开开发者模式。
5. 按系统提示重启 iPhone。
6. 重启后再次确认启用开发者模式。

然后回到 Xcode，再点 Run。

## 8. 安装后第一次打开

如果 iPhone 提示需要信任开发者：

1. 打开 `设置`。
2. 进入 `通用`。
3. 进入 `VPN 与设备管理` 或 `设备管理`。
4. 找到你的 Apple ID / Developer App。
5. 点信任。

然后回到桌面打开「心绪日记」。

## 常见错误

### Signing requires a development team

含义：还没选 Team。

处理：

1. `TARGETS -> HeatMoment -> Signing & Capabilities`
2. 勾选 `Automatically manage signing`
3. `Team` 选择你的 Apple ID / Personal Team

### Team 下拉框为空

处理：

1. Xcode 菜单打开 `Settings...`
2. 进入 `Accounts`
3. 点 `+`
4. 登录 Apple ID
5. 回到 `Signing & Capabilities` 选择 Team

### Personal development teams do not support the iCloud capability

当前默认工程已经关闭 App target 的 iCloud entitlement。如果还看到这个错误，通常是 Xcode 没有重新加载新生成的工程。

处理：

1. 关闭 Xcode 当前项目窗口。
2. 在仓库根目录重新执行：

   ```bash
   ./scripts/gen.sh
   ```

3. 重新打开 `HeatMoment.xcodeproj`。
4. 确认 `Signing & Capabilities` 里没有 `iCloud` capability。
5. 再 Run。

### Build Failed 只显示三行失败

Xcode 最后的 `BUILD FAILED` 只是汇总，不是真正原因。

查看真实错误：

1. `Cmd + 5` 打开 Issue Navigator。
2. 或 `Cmd + 9` 打开 Report Navigator。
3. 点最新失败的 build。
4. 找第一条红色错误。

优先处理第一条红色错误，后面的失败通常是连带结果。
