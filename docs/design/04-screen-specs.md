# 页面清单与页面级交互

> 职责说明：逐一列出 19 个 View 的内容、交互、状态与无障碍要点（`DatePickerSheetView` 与 `TimePickerSheetView` 是两个独立 View，合并在同一小节 §4.8 描述）。

> 本章每页只描述「有什么 / 点了怎样 / 有哪些状态 / 无障碍要点」，配色、字号、组件视觉样式参见《05-design-system.md》。

## 4.1 TimelineHomeView（首页时间轴）

- **内容**：顶部三入口（日历方块 / 中间标题 / 六边形设置）；上下文标记横条（有筛选或定位时显示，见下）；聊天气泡式时间轴列表，每条左列时间戳 + 心情节点，节点**按该条情绪的心情色**着色（每情绪一色，见《05-design-system.md》，非固定青色/统一色点）；底部悬浮新建按钮。
- **标题的两态（large title 折叠）** `[真机确认交互 + 设计决策：用户裁决 B]`：滚到顶时中间为**大标题「时刻」**——纯场景标识、**不可点、不触发筛选**；时间轴上滑后大标题**折叠进顶部栏**，成为**收起态 inline「时刻 ⌄」**；**筛选入口只在收起态承担**——点收起态「时刻 ⌄」才打开 `FilterPanelView`（就地筛选半屏 sheet），大标题展开态点击无筛选动作。
- **交互**：
  - 点日历方块 → 展开 `YearHeatmapView`。
  - 点**收起态**标题「时刻 ⌄」→ 打开 `FilterPanelView`（就地筛选半屏 sheet；大标题展开态不触发，见上「标题的两态」）。
  - 点六边形 → 打开 `SettingsSheetView`。
  - 点卡片 → **弹出 `MomentPreviewView` 阅读卡片**（进入任务卡片栈，非页面 push，见 §4.9）。
  - 卡片左滑 → 日期、心情节点、moment 气泡作为一个记录整体左移，露出删除动作 → 软删除进垃圾箱；不弹二次确认。
  - 点悬浮按钮 → 打开 `MomentEditorView`（新建态）。
  - 不提供手动下拉刷新（本地数据即时可见；CloudKit 远程变更由 `@Query` 自动反映到时间轴，`[设计决策]`）。
  - 滚动到底部触发分页加载下一页（见《12-quality-assurance.md》）。
- **上下文标记**：横条表达「当前查看条件」，分两类且**可并存、各自可移除**——筛选标记（`#标签` / 情绪 emoji+名称，说明「只看命中条件的记录」）与时间标记（年/月/日，说明「已定位到某时间点」，来自热力图）。移除筛选标记改变「看哪些记录」，移除时间标记改变「是否停在某时间位置」，二者正交（见《03-user-flows.md》3.3）`[设计决策]`。
- **状态**：空数据态（仅 3 条预置引导 Moment）；有筛选态（筛选标记 + 数据集合缩小）；定位态（时间标记 + 某一时间段高亮，来自热力图）；筛选+定位并存态；正常浏览态。
- **无障碍**：每张卡片 `accessibilityElement(children: .combine)`，label 汇总「5月17日 17:06，心情开心，标题《XXX》」；左滑删除同时提供 `accessibilityAction(.delete)` / `accessibilityCustomAction("删除")`，不依赖手势也可完成删除；悬浮新建按钮 label 为「新建时刻」。

## 4.2 FilterPanelView（标签/心情筛选面板）

- **呈现** `[交互模型 v2 修订]`：**首页就地筛选半屏 bottom sheet**——点首页收起态标题「时刻 ⌄」从底部升起，覆盖在主页之上，主页仍是当前上下文。它不是导航式任务页，不 push 新页面，不进入任务卡片栈，不进 `AppRouter.rootSheet`；由触发处局部 `@State` 驱动，使用系统 sheet detent（默认半高，可上拉到全高），支持 drag handle / 系统下滑关闭。内嵌 `NavigationStack` 只服务 sheet 内标题和「完成」按钮，「完成」仅收起 sheet（不做提交）。
- **内容**：**心情区**（复用 `Mood.allCases` 顺序，**单选**，可切回「全部心情」）；**标签区**（含用户已建标签，**多选**，可清空标签条件，无标签时展示引导创建提示），标签区**末尾有「+ 新增标签」入口**。底部提供「清除全部」，同时移除心情与标签筛选；已选条件通过行内勾选态标记。
- **筛选组合逻辑** `[设计决策：用户裁决，见《13-open-questions.md》#19]`：**标签可多选，选中的多个标签之间按 AND（同时满足所有选中标签，交集）**；**心情单选（一次一个）**；标签维度与心情维度之间也是 AND。即最终条件 =（含全部选中标签）且（命中所选心情，若选了）。
- **交互**：每次点选**即时更新**筛选结果（就地，无「确认」按钮，`[观测确认]`）；筛选结果立即作用于首页时间轴、上下文标记和热力图口径；因标签支持多选，sheet **不因单次点选而关闭**，可连续点多个标签累加条件；再次点已选项取消该项；点「完成」或下滑收起 sheet（收起不改变已生效的筛选）；首页上下文标记横条上的 X 可单独移除某条件或清空全部。
- **交互边界**：筛选只改变「看哪些记录」；热力图只改变「定位到哪个时间位置」。二者可同时存在，但不得合并为同一个筛选/定位状态。
- **新增标签子级 sheet**：标签区「+ 新增标签」唤起 `TagCreateSheetView`（第二层 `.sheet`，由本面板局部 `@State` 驱动，复用编辑器/标签管理同一实现）；创建成功后把新标签 id **自动加入当前筛选条件（立即可筛，无需再手动勾选）**。
- **状态**：无标签时展示引导创建标签的空态提示 `[设计决策]`。
- **无障碍**：每个候选项 `accessibilityAddTraits(.isButton)`，选中态通过 `accessibilityValue("已选中")` 而非仅靠视觉勾选传达。

## 4.3 YearHeatmapView（年度心情热力图，主页顶部上下文区）

- **呈现**：从首页顶部日历入口展开后，成为导航栏下方的稳定上下文区域，参与主页布局；不是独立页面、不是 sheet，也不是漂浮在内容上的临时卡片。展开/收起本身不改变时间轴滚动位置，只有用户点月或点日后才进入时间定位语义。
- **内容**：顶部年份「2026 ⇅」下拉选择 2021–2026；右侧 X 关闭；横向可滚动网格，底部月份标签；**有记录的日期格用「当天最后一条时刻的心情色」着色**（表达当日情绪印象，每情绪一色，见《05-design-system.md》，非固定青色）；无记录日期为空态格。
- **交互**：选月/选日 → 时间轴定位滚动（不改变数据集合，见《03-user-flows.md》3.3）；再次点同一锚点取消定位；点 X 收起热力图上下文区。
  - **点月**：月份入口隐藏在底部月份标签/月份区域中，不额外做醒目的按钮。点月后，当前月份对应的热力图区域显示一层与设置页主色一致的轻微透明蒙层，表达“当前定位到这个月”；定位目标为该月在当前筛选口径下的真实记录，而不是伪造月份节点。
  - **点日**：日期格显示日期级选中态，并定位到该日对应的真实记录。月定位与日定位同属时间 anchor，不得改写标签/心情筛选。
- **状态**：空月/空年 →「这些天没有日记哦」+ 插画。
- **无障碍**：年份选择器作为可调整值控件（`accessibilityAdjustableAction` 支持上下滑动切换年份）；每个有记录日期格 label 为「7月5日，有记录，当日心情开心，点击定位」，不依赖颜色单独传达情绪。

## 4.4 MomentEditorView（新建/编辑 Moment）

- **内容**：顶栏「取消 | 日期chip + 时间chip | 保存」；情绪选择器行（❤️+当前情绪+⌄）；标签选择器行（#+已选标签+⌄）；标题输入；正文输入；照片区（未加时为「添加照片」大按钮，已加后为「日志图片 N 张」+ ⊕ 追加 + 缩略图 ⊖ 删除角标）。
- **交互**：见《03-user-flows.md》3.1 全流程图；日期/时间 chip 各自打开独立弹层（`DatePickerSheetView` / `TimePickerSheetView`）；点保存前做限额与必填校验。
- **状态**：新建态（默认预填当前时间）/ 编辑态（预填已有数据）；限额拦截态（照片第4张、标签第4个触发 Paywall）；未保存离开确认态。
- **无障碍**：情绪/标签行按钮 label 完整朗读当前值，如「情绪，开心，双击更改」；照片缩略图的 ⊖ 删除角标提供 `accessibilityCustomAction("删除该照片")`，避免小触控靶点依赖精细点击（视觉靶点尺寸由《05-design-system.md》保证，这里保证有非手势替代路径）。

## 4.5 MoodPickerView（情绪选择弹层）

- **呈现**：**就近浮窗**——从编辑器情绪行锚点旁就近弹出，带尖角，背景不下沉、不入层级栈，保持编辑卡片大部分可见；跨设备（含 iPhone）保持浮窗形态、不降级半高 sheet。
- **内容**：`Mood.allCases` 8 项列表（正常/开心/难过/焦虑/恐惧/愤怒/厌恶/激励），emoji+名称，当前项右侧 ✓。
- **交互**：点选即选中并关闭弹层，回填编辑器情绪行；点浮窗外部也收起。
- **无障碍**：整体作为单选列表语义（`accessibilityTraits: .isSelected` 标记当前项），支持 VoiceOver 上下滑动逐项朗读。

## 4.6 TagPickerView（标签选择弹层）

- **呈现**：**就近浮窗**——从编辑器标签行锚点旁就近弹出，带尖角，背景不下沉、不入层级栈；跨设备保持浮窗形态。（注：其内的「+添加」入口所打开的 `TagCreateSheetView` 属任务卡片栈，是完整任务，见 §4.7。）
- **内容**：已有标签列表（如 #工作），末尾「+添加 +」入口。
- **交互**：点已有标签即选中，**支持多选**（已裁决，一条 Moment 可挂多个标签，对应 Moment↔Tag 多对多关系）；点「+添加」打开 `TagCreateSheetView`。
- **状态**：已达免费标签上限时「+添加」点击触发 Paywall，而非直接打开创建弹窗。

## 4.7 TagCreateSheetView（新建标签弹窗）

- **内容**：居中卡片，标题「# 标签名称」，输入框占位「输入新的标签名」，主色「保存」+「取消」。
- **交互**：保存时做重名校验（同名标签不可重复创建，`[设计决策]`，因 CloudKit 不支持唯一约束，需应用层校验，见《07-data-persistence.md》）；保存后自动回填到调用方（编辑器标签行 或 `TagManageView` 列表）。
- **无障碍**：输入框 `accessibilityLabel("标签名称输入框")`；保存按钮在输入为空时禁用并有对应 `accessibilityHint`。

## 4.8 DatePickerSheetView / TimePickerSheetView（发生时间就地选择）

- **呈现**：两者均为**就近浮窗**——从编辑器顶栏的日期 chip / 时间 chip 锚点旁就近弹出，带尖角，背景不下沉、不入层级栈，保持编辑卡片大部分可见；优先在锚点下方展开、空间不足翻转到上方；跨设备（含 iPhone）保持浮窗形态、不降级半高 sheet（命名中的 Sheet 为历史 View ID，呈现语义以此处为准）。
- **内容**：日期——日历弹窗（‹›翻月，标题 ⌄ 可切年月滚轮，选中日为实心圆，截图中呈紫色）；时间——时/分双滚轮。
  - 注：该选中圆到底用**主色**还是**主文本色**存在待核实矛盾（截图主色恰为紫，二者难分；真机观测确认热力图日期选中用主文本色），见《13-open-questions.md》。
- **交互**：支持选择任意过去/未来日期时间以支持「补记」；选择后立即回填编辑器顶栏 chip 文案，不需要额外确认按钮（`[真机确认 + 设计决策]`，若产品需要显式确认按钮，列为开放问题）。
- **无障碍**：滚轮组件遵循系统 `Picker`/`DatePicker` 原生无障碍行为，不做自定义手势覆盖，保证 VoiceOver 用户可用系统标准方式调整。

## 4.9 MomentPreviewView（单条 Moment 预览）

- **呈现**：**弹出的阅读卡片**——点时间轴一条时刻，在当前时间轴**之上浮起一张阅读卡片**（进入任务卡片栈，背景时间轴下沉、缩小、露在后面），**不是 push 跳转到另一页面**；关闭最前一层即回到时间轴（见《14-design-decisions.md》任务卡片栈层级）。
- **内容**：顶部心情、日期、编辑入口；正文区标题、标签、照片、正文全文。
- **交互**：点编辑入口 → 打开 `MomentEditorView`（编辑态，在卡片栈上再叠一层）；点图片 → `ImageViewerView`；关闭手势/关闭按钮关闭阅读卡片，回到时间轴（保持原滚动位置）。
- **无障碍**：作为浮起的阅读卡片，VoiceOver 焦点在卡片弹出完成后应移动到卡片标题（`accessibilityFocused` 处理），避免焦点仍停留在已下沉的时间轴卡片上；卡片对底层时间轴做模态隔离（`.isModal`），防止焦点穿透。

## 4.10 ImageViewerView（图片查看器）

- **内容**：全屏图片浏览，支持横向滑动多图、缩放手势、关闭手势/按钮。
- **交互**：从 `MomentEditorView` 缩略图或 `MomentPreviewView` 照片区进入；支持捏合缩放、双指/双击放大。
- **无障碍**：每张图片 label 为「照片，第 N 张，共 M 张」，不做 AI 自动生成图片描述（避免隐私顾虑与不必要的网络请求，`[设计决策]`）。

## 4.11 SettingsSheetView（设置）

- **内容**：标题「设置」；Pro 横幅（升级引导文案+价格提示）；分组卡片 A（心情统计、标签、垃圾箱）；分组卡片 B（iCloud 数据同步、面容解锁、语言、外观主题）；「关于心绪日记」；作者其他应用展示区（占位，不承诺跳转行为）；底部版本信息。
- **交互**：各行点击 push 到对应子页（`MoodStatsView` / `TagManageView` / `AppearanceThemeView` / `AboutView`），或触发系统行为（语言切换、面容解锁开关）；Pro 横幅点击打开 `ProPaywallView`。
- **状态**：Pro 会员态下横幅已裁决——升级引导横幅替换为「已是 Pro 会员」态（《13-open-questions.md》问题 11 已裁决）。
- **无障碍**：每个分组行作为整体可点击元素，label 包含标题+当前值（如「iCloud 数据同步，已同步」）。

## 4.12 MoodStatsView（心情统计页）

- **内容**：顶栏「‹设置 | 年份 2026（可选 2021–2026）」；卡片1「心情日期分布」热力图（行=周日~周六，列=月份，格=日期）；卡片2「心情统计」8 情绪条形图（emoji+名称+N次+占比进度条）。
- **交互**：切换年份刷新两个卡片数据；卡片1不承担定位时间轴功能（与首页 `YearHeatmapView` 是两个独立组件，仅视觉范式相似，`[设计决策]`）。
- **无障碍**：统计条形 label 为「开心，3次，占比XX%」，不依赖颜色传达占比信息。

## 4.13 TagManageView（标签管理）

- **内容**：标题「标签管理」，`‹设置` 返回，右上「+」；列表项「# 工作」等。
- **交互**：右上「+」→ `TagCreateSheetView`；列表项点击进入重命名（复用 `TagCreateSheetView` 的重命名态，预填原名，`[设计决策]`）；滑动删除标签（删除只解除关联，不触发垃圾箱生命周期，见《03-user-flows.md》3.4）。
- **无障碍**：删除动作提供 `accessibilityCustomAction("删除标签")`。

## 4.14 TrashView（垃圾箱）

- **内容**：已软删除的 Moment 列表，按 `deletedAt` 倒序排列，样式沿用时间轴卡片范式。
- **交互**：右滑恢复（`isDeleted=false`）；左滑彻底删除（弹二次确认，因为该操作不可逆，`[设计决策]`，与首页删除的「无需确认」形成对比，理由是首页删除有安全网、这里没有）。
- **状态**：空状态「垃圾箱是空的」 `[设计决策]`。
- **无障碍**：恢复/彻底删除均提供 `accessibilityCustomAction`。

## 4.15 AppearanceThemeView（外观主题）

- **内容**：标题「主题颜色」；分组「模式」（暗色/亮色）；分组「颜色」（6 主色圆）；分组「网格」（网格线/点阵/无）；分组「图片」（滚动/轮播）。
- **交互**：即时生效（乐观更新：先改界面再存偏好），无保存按钮；只影响呈现，不改内容/标签/统计（见《03-user-flows.md》3.4 及《07-data-persistence.md》本地存储范围）；主色的影响边界见《05-design-system.md》，保存失败/坏配置的异常反馈（「外观设置保存失败」「照片显示设置保存失败」「已修正 N 项本地偏好配置」）见《05-design-system.md》。
- **无障碍**：颜色选择项额外提供颜色名称 label（如「主色：紫罗兰」），不能只依赖色块本身传达信息。

## 4.16 AboutView（关于）

- **内容**：App 图标；「Moodments」+ 版本号；备案号；「关于创作者」卡片（跳转小红书）；「隐私协议」「使用条款」卡片。
- **交互**：点击卡片打开对应外部链接或静态协议页（WebView 或本地渲染文本）。

## 4.17 ProPaywallView（Pro 订阅页）

- **内容**：顶部左 ⌄ 收起、右「核销码」；大标题「月订阅」+ 副标题；三条权益卡片（无限日记/无限照片/无限标签，均带「普通用户最多…」对比文案）；价格区含**月订阅 ¥6.0/月**（`Product.displayPrice` 动态取值，不写死）与**终身买断**两个方案（终身买断为新增，见下）；红色大按钮「解锁所有功能」（按选中方案购买）；底部「隐私协议 | 使用条款」+「恢复购买」。
- **交互**：见《03-user-flows.md》3.5；用户在月订阅/终身买断间二选一后点 CTA 购买；核销码入口按平台能力条件展示。
- **终身买断的呈现** `[设计决策，超出原 App]`：真机截图只有单一月订阅布局，新增终身方案后需把价格区改为「双方案可选」（如上下两张方案卡或分段选择器），此视觉为新增设计，须在原型阶段确认，不属于 `[真机确认]`。
- **状态**：购买中 loading 态；购买失败错误提示；已是 Pro 态（理论上不应再看到此页，除非从设置横幅误触，需做态度提示「您已是 Pro 会员」，`[设计决策]`）。
- **无障碍**：权益卡片 label 完整朗读对比文案；价格与按钮合并为一个可操作元素，避免拆碎朗读。

## 4.18 PrivacyLockView（隐私锁）

- **内容**：全屏遮罩（品牌 Logo + 解锁提示），无返回/关闭手势。
- **交互**：见《10-security-privacy.md》。
- **无障碍**：`accessibilityAddTraits(.isModal)`，防止 VoiceOver 焦点穿透到底层内容；提供「使用密码」按钮作为生物识别失败后的可达路径。
