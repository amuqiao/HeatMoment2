# 心绪日记 / 时刻 / Moodments —— 设计文档体系

本目录是「时刻」(App Store 商店名「心绪日记」,关于页 App 名 Moodments)iOS 复刻项目的**设计文档体系**,按标准 iOS 应用设计文档组织,面向后续开发落地。目标技术栈:SwiftUI,iOS/iPadOS 17+,iPhone + iPad。

> **来源溯源**:本体系最初基于该 App 的真机截图与产品行为观测建立;建立后作为**独立文档体系自维护**,不再关联最初的观测草稿,后续以本目录内容为唯一准绳演进。

> **上游公理层**:本 `design/` 目录是产品公理层 [`../product-mental-model.md`](../product-mental-model.md) 的**实现层（下游）**。公理层定义产品对象、跨位置一致语义与不可违背的规则;本目录把这些公理落成真机级的页面、流程与规格。二者冲突时以公理层为准,应回改设计。

## 标注体系

全文对具体事实标注来源,便于判断可信度与可改动性:

| 标注 | 含义 |
|---|---|
| `[真机确认]` | 真机截图直接可见的事实 |
| `[真机确认,取色]` | 从真机截图像素取色测得的色值 |
| `[观测确认]` | 真机行为观测确认（截图未直接展示，但已确认可信） |
| `[设计决策]` | 基于同类 iOS App 范式与工程常识做出的复刻决策，可在评审阶段调整；`[设计决策，超出原 App]` 表示原 App 无此项、为本项目主动新增（如终身买断） |

组合标注（如 `[观测确认 + 设计决策]`）表示该条同时含已确认事实与设计推断两部分。

## 术语表

| 术语 | 说明 |
|---|---|
| Moment | 一条生活时刻记录（核心内容对象），含发生时间/情绪/标签/标题/正文/照片，见 `07-data-persistence.md` |
| Mood | 8 种并列情绪枚举（正常/开心/难过/焦虑/恐惧/愤怒/厌恶/激励），持久化契约，见 `06-domain-model.md` |
| Tag | 事件标签，与 Moment 多对多关联，见 `07-data-persistence.md` |
| 时间轴定位 vs 筛选 | 热力图定位改滚动位置、筛选改可见数据集合，两个独立状态源，见 `03-user-flows.md`、`08-architecture.md` |
| 软删除 / 垃圾箱 | Moment 删除先进垃圾箱（`isDeleted=true`）可恢复，彻底删除才物理移除且才释放免费额度，见 `03-user-flows.md` |
| 组合式主题 | 模式×主色×背景纹理×图片展示的自由组合，非预设皮肤，见 `05-design-system.md` |
| 心情色 | 每种情绪拥有唯一的心情色（8 情绪各一色），是**跨时间轴节点、热力图日期格、心情统计三处一致的数据语义色**，表达同一情绪身份，不是任何一处的局部装饰、也无「固定青色/统一色点」；色值见 `05-design-system.md`，语义见 `../product-mental-model.md` |
| 主色语义 | 主色只驱动「强调色」，不改心情色/危险色/中性基底/内容，见 `05-design-system.md` |
| View ID | 各页面的 SwiftUI View 命名（TimelineHomeView 等），跨文档共用，见 `04-screen-specs.md`、`08-architecture.md` |

## 维护约定

- 新增/修改事实时保持标注体系;凡涉及具体数字（限额、价格、版本）优先归 `[真机确认]` 或 `[设计决策]`，凡涉及色值/字号/动效归 `[真机确认,取色]` 或 `[设计决策]`。
- 免费/Pro 限额、情绪枚举等**契约**只在 `06-domain-model.md` 定义一次，其他文档引用不重复定义数值。
- 决策一旦拍板，更新 `13-open-questions.md` 的裁决状态，并把结论落到对应专章。
